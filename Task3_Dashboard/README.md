## 📌 Core KPIs Defined

| Average Order Value | SUM / COUNT(Orders) | ₹1.39L |
| Repeat Customer Rate | Repeat Customers / Total | 5.6% |
| Revenue per Customer | Total Revenue / Unique Customers | ₹1.47L |
| Category Contribution | Category Revenue / Total | Electronics 36.5% |

## 🔍 Deep-Dive: Customer Segmentation (RFM)

Customers are scored 1–5 on Recency, Frequency, and Monetary value, then grouped into
7 actionable segments:

| Segment | Description | Recommended Action |
|---|---|---|
| Champions | Best customers — recent, frequent, high spend | VIP treatment |
| Loyal Customers | Buy regularly, good value | Reward programme |
| At Risk | Used to buy frequently but haven't recently | Win-back campaign |
| New Customers | Bought recently, only once | 2nd purchase incentive |
| Promising | Recent, medium frequency | Nurture sequence |
| Potential Loyalists | Moderate recency, low frequency | Cross-sell |
| Lost | Inactive, low frequency | Final re-engagement |

---

## 💡 Key Findings

- **Repeat Customer Rate is only 5.6%** — biggest growth lever is retention, not acquisition
- **Champions** contribute a disproportionately high share of revenue (Pareto effect)
- **At Risk customers** need urgent win-back campaigns before they become Lost
- **Electronics drives 36.5%** of total revenue across all segments
- **5 KPIs** formally defined with formulas and business rationale

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone https://github.com/mauryasai198/ApexPlanet_Task3_Dashboard.git
cd ApexPlanet_Task3_Dashboard

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the RFM segmentation analysis (generates charts + report)
python analysis/segmentation_analysis.py

# 4. Launch the interactive dashboard
python dashboard/app.py
```

Then open your browser at **http://127.0.0.1:8050**

The dashboard has live filters for **City, Category, and Gender** — all KPI cards
and charts update instantly when you change a filter.
